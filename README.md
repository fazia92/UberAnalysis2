#  Uber Trip Analysis Dashboard  

This project provides an **interactive Power BI dashboard** to analyze Uber trip data.  
The dashboard highlights key insights about bookings, revenue, distances, trip types, and customer behavior. 

---

# Dashboard Features  
The dashboard allows users to:  
- Track **key KPIs**:  
  - Total bookings  
  - Total miles  
  - Total revenue  
  - Average distance  
  - Average revenue per trip  
  - Average trip time  
- Analyze trips by:  
  - **Trip type** (Day Trip vs Night Trip)  
  - **Payment method** (Uber Pay, Cash, Amazon Pay, Google Pay)  
  - **Location** (Manhattan, Queens, Brooklyn, etc.)  
  - **Day of the week** (Monday → Sunday trends)  
  - **Vehicle type** (UberX, Uber Comfort, Uber Black, UberXL, Uber Green)
